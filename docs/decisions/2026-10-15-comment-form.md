# 决策：注释形态（`/** */` 的落点）

状态：已接受
日期：2026-10-15

背景：注释规则已收敛到「谁必须有注释」这一个判据，但**形态**从未定义，于是同一件事有三种写法混用
（`/** */`、`//`、`/* */`），没有判据能说明该用哪个。其中只有一种有实质后果，而现行条文的理由写偏了。

`tsc --declaration` 实测：

- `/** */` **进 `.d.ts`**；`//` 与 `/* */` 都不进。
- 文件级 `/** */` 直接压在首个声明上时，会与该声明的文档并排出现在 `.d.ts` 里，被读成它自己的文档。
- 因此 `/** */` 只服务两类读者：IDE 的 hover，与解析 JSDoc tag 的工具。

现行条文给的两个补救有一个是错的：「把它放在 import 之前」只挡得住门禁误挂，挡不住 `.d.ts` 泄漏
（实测 `runtime-trace-plugin.ts` 的前言照样出现在 `dist/`），且文件没有 import 时无处可放。

选项：

- (a) 维持现状，只把理由改写清楚：成本最低，但「三种形态」的信号值是零 —— 看到 `/* */` 无法判断
  它是普通散文，还是本该写成 `/** */` 的东西。
- (b) 二态：`/** */` 只留给「删掉它，有工具的行为会变」的地方，其余一律 `//`（选定）。
- (c) 三态：保留 `/* */` 承担长段落说明：减少改写量，但放弃 (b) 的信号值；且 `/* */` 相对 `//`
  没有任何机械优势（同样不进 `.d.ts`、同样不被门禁认领）。

决策：采用 (b)。

理由：`/** */` 的存在本身就是「这里有符号文档」的信号，而本仓的主要读者是 Agent —— 它需要一个便宜
可靠的启发式来判断「这里是符号边界还是内部说明」。第三种写法会让这个信号失效。

边界按**功能**划，不按清单划 —— 清单必然过时（`@__NO_SIDE_EFFECTS__` 是 Rollup 后来才加的）：

- 会变的两类：**会被调用方 hover 的符号文档**；**带 JSDoc tag 的注解**（`@deprecated`、`@internal`）。
  实测重导出（`export … from`）上的 `@deprecated` 会进 `.d.ts`，换成 `//` 会**静默丢掉**消费方的
  删除线提示。
- JSX 的 children 是**标记**而不是代码，直接写在那里的 `//` 会渲染成页面上可见的文字；而 `{// …}`
  同行写会把右花括号一起注释掉。故 `.tsx` 里注释写成 `{/* … */}`。
- `/* @__PURE__ */`、`/* @vite-ignore */`、`/* webpackChunkName: … */` 是**构建元数据**，借了注释的
  语法而不是注释；形态与位置由各工具规定（多数在表达式中间，`//` 在语法上无法替代）。

后果：

- 共享件 `skills/red-bean-*-coding-conventions/references/common.md`（两仓三份，逐字相同）新增
  「注释形态」，`## 注释` 由四节变五节；并删除原「文件级说明……或改用普通块注释」那一条 —— 它给的
  两个补救都被 (b) 取代，其中「放在 import 之前」已被实测证伪。
- **存量偏离随本规则一并清理，两仓归零**。枚举判据：`/** */` 未被在场符号认领。

  | 仓 | `/** */` 改前 → 改后 | 改写 | `/* */` 改前 → 改后 | 改写 |
  | --- | --- | --- | --- | --- |
  | SDK | 1431 → 1382 | 49 | 2 → 0 | 2 |
  | 产品 | 4922 → 4670 | 252 | 167 → 42 | 125 |

  合计 **428 处**。**合法保留**：带 JSDoc tag 的 3 处（`@deprecated` 重导出，实测会进 `.d.ts` 并给
  消费方删除线）；JSX 表达式容器里的 `{/* */}` **42 处**。另有 **39 处文件级前言**属于有实质后果的
  一类 —— 它们会原样漂进 `.d.ts`，其中 SDK 的 `src/runtime/public-api.ts` 等本就是
  `package.json#exports` 的 types 目标。
- 注释形态**尚未机检**：判据依赖「全部 JSDoc 块」这份事实，而语法层目前只产出每个符号自己的前导
  JSDoc。规则正文已写明这一点，避免读者误以为它已被拦住；并入门禁需要先扩展两个仓各自的
  `architecture-syntax.mjs` —— 届时**不要用 `ts.createScanner` 枚举注释**：它遇到模板字面量会失步
  （不调用 `reScanTemplateToken`），随后的注释全部扫不到。本次第一遍正是因此漏了 129 处，只有在
  含 `${}` 的文件里才暴露。可靠做法是把 AST 展到叶子 token，取相邻 token 之间的空隙 —— 那里只可能
  是 trivia。
- 改写 SDK 仓 `src/**` 中进入 `.d.ts` 的前言会改变声明基线，必须重生成
  `testdata/api/public-declarations.sha256`（`make ts-decl-baseline-update`）；注意该漂移只在
  `make verify` 暴露，`verify-quick` 不含构建。
- 按「冻结记录只追加不修改」，不回写 `2026-10-13-export-jsdoc-gate.md` 里「注释章节分四节」的
  现状陈述 —— 它描述的是决策时点，本文件记录当前事实。
